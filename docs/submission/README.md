# Submission materials

Everything needed for the Devpost form for the Nebius x NVIDIA Global AI Hackathon (deadline October 30, 2026, 10:00 a.m. Pacific).

| File | Use |
| --- | --- |
| [DEVPOST.md](DEVPOST.md) | Project name, pitch, track, links, built-with tags, and every write-up section |
| [TESTING.md](TESTING.md) | Testing instructions field (hosted and local options) |
| [FEEDBACK.md](FEEDBACK.md) | Feedback on Token Factory, AI Cloud, and NVIDIA tools |
| [DEMO_SCRIPT.md](DEMO_SCRIPT.md) | Shot list and narration for the video |

## Before submitting

- [ ] Record and upload the video (public on YouTube), then fill in the video link.
- [ ] Fill in the hosted URL, or delete option A in TESTING.md and point judges at the test build.
- [ ] Add the hosted URL to the GitHub repository's About section, if hosted.
- [ ] Select the Coding and Agentic Engineering track.
- [ ] Confirm the repository is public and the MIT license shows in the About section (it does as of October 4).
- [ ] Make sure judges can use the project free of charge through December 15, 2026.
